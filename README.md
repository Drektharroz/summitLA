# Summit Legal Advisors - Sitio corporativo premium

Rediseño integral del sitio estático de **Summit Legal Advisors** con enfoque editorial, sobrio y ejecutivo para una firma legal boutique.

## Incluye

- Home con arquitectura premium de conversión (hero, propuesta, servicios, metodología, autoridad, contextos, insights y contacto).
- Sistema visual refactorizado con tokens CSS (`:root`), jerarquía tipográfica y grilla responsive.
- Interacciones ligeras en JavaScript vanilla (menú mobile, estados activos por scroll, reveal sutil y utilidades UX).
- Estructura compatible con GitHub Pages (sin bundlers ni frameworks).

## Ejecutar localmente

Puedes abrir `index.html` directamente en el navegador.

Si prefieres levantar un servidor local:

```bash
python3 -m http.server 4173
```

Luego visita `http://localhost:4173`.
